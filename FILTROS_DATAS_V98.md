# VALLE v98 — Datas iniciais vazias

- Aba **Lançamentos**: DATA INICIAL e DATA FINAL começam vazias.
- Aba **Histórico**: DATA INICIAL e DATA FINAL começam vazias.
- Quando uma ou ambas as datas estiverem vazias, o filtro não limita os dados por esse lado.
- O botão **LIMPAR FILTROS** deixa as duas datas vazias.
- Service Worker/manifest foram incrementados para v98 para forçar a atualização no PC, Android e iPhone.
