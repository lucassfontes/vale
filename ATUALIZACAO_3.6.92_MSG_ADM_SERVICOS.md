# VALLE 3.6.92 — MSG ADM para usuários de serviço

- A MSG ADM agora é verificada por usuários de **sessão** e de **serviço**.
- Usuário de serviço recebe mensagens globais e mensagens direcionadas à sua sessão.
- Cada usuário possui controle de leitura independente.
- Incluído SQL para substituir políticas antigas que bloqueavam role=service.
