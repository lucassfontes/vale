# VALLE 3.6.52 — Nome do cliente em uma linha no modal Ver Contrato

- O nome do cliente no cabeçalho do modal **Ver contrato** agora fica em **uma única linha**.
- A fonte reduz automaticamente para caber melhor no espaço disponível.
- Quando o nome é muito grande, o sistema faz **abreviação inteligente do sobrenome**.
- O nome completo continua disponível no atributo `title` do elemento.
