# VALLE 3.6.57 — Lançamentos do crediário na Área do Cliente

- Ao clicar no card de um crediário, abre um modal com os lançamentos somente daquele contrato.
- Foram criados os filtros **PAGOS**, **A PAGAR** e **INFORMADOS** com contadores.
- Em **A PAGAR**, o cliente pode abrir o pagamento PIX diretamente pelo botão **PAGAR**.
- **INFORMADOS** exibe pagamentos enviados e aguardando/confirmados para conferência.
- Layout responsivo para celular e desktop.
